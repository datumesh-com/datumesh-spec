# Datumesh logo

- `datumesh.svg`, `datumesh.png`: the logo as supplied (500×500, transparent background).
- `datumesh-logo.svg`: the same SVG with its `viewBox` cropped to the artwork (`71 81 233 251`). Use this one in layouts.
- `datumesh-mark.svg`: the same SVG with its `viewBox` cropped to the sphere (`88 85 180 180`). Use it for favicons and small sizes.

Prefer the SVGs. Use the PNG only where SVG is not supported (link previews, iOS home-screen icons).
